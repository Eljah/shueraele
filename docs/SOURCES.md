# Источники и границы проверки

Дата подготовки: 28 сентября 2026. Собственные проектные решения, размеры и результаты тестов описывают этот репозиторий, а не спецификацию Meta.

1. **Khronos, glTF 2.0 Specification** — нормативная структура GLB, nodes, transforms, materials. Прочитан первоисточник: https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html . Наша структурная проверка не является сертификацией Khronos.
2. **Опубликованные TypeScript-декларации Spark**: https://github.com/Enuriru/spark-ar-types/tree/main/PublicTypes . Прочитаны `HandTracking.Hand/index.d.ts` и `HandTracking/index.d.ts`; GitHub сообщает дату последнего изменения этих файлов 2022-05-22. Это сторонняя публикация деклараций, не поставляемый Meta SDK и не доказательство поведения каждой последующей версии. Набор полей Hand в этом снимке: `boundingBox`, `cameraTransform`, `isTracked`; модуль предоставляет `count` и `hand(index)`. Наш код намеренно ограничен этим контрактом; отсутствие суставов в данном снимке не означает доказанное отсутствие всех расширенных API во всех версиях Spark.
3. **Meta Incubator, spark-ar-core-libs**: https://github.com/facebookincubator/spark-ar-core-libs . Проверена структура официального репозитория: отдельные библиотеки mocks и e2e tests существуют. Код оттуда не скопирован; наши двойники написаны для этого проекта и не являются официальной эмуляцией движка.
4. **Playwright Python, Screenshots** — первичная документация метода снимков реального браузера: https://playwright.dev/python/docs/screenshots . Скриншоты в `evidence/` создаёт `page.screenshot`; они не нарисованы генеративной моделью.
5. **Meta Spark announcement** — исторический адрес объявления: https://spark.meta.com/blog/meta-spark-announcement/ . При текущем обращении страница выдала блокировку, не содержимое объявления. Архивный адрес, использованный ранее в обсуждении: https://web.archive.org/web/20250304224509/https://spark.meta.com/blog/meta-spark-announcement/ . Содержимое архива повторно здесь не проверено. Проект не опирается на предполагаемый работающий сервис публикации.

Не использованы неизвестные инсталляторы, модели распознавания Meta, чужие логотипы, обходы авторизации или закрытые сетевые API. Анатомия и рисунки — авторская стилизация этого комплекта, не реконструкция конкретной исторической иллюстрации Шүрәле.
